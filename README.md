# Text Summarizer - AI Powered

A beautiful, fast, and simple web app that summarizes any long text using **Google Gemini AI**.

Built with pure HTML, Tailwind CSS, and JavaScript. No backend required.


## ✨ Features

- Clean and modern dark UI
- Real-time character counter
- Powered by **Google Gemini 2.5 Flash** (fast & accurate)
- One-click "Copy Summary"
- Keyboard shortcut: `Ctrl + Enter` to summarize
- Fully responsive design
- Single HTML file (easy to deploy)

## 🚀 Live Demo

[View Live Demo](https://sensational-centaur-20f359.netlify.app/)  

## 🛠️ How to Use

1. Paste any long text (article, essay, report, notes, etc.)
2. Click **"Summarize"** button
3. Get a clean, concise summary in seconds
